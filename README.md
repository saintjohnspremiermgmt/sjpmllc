# Saint Johns Premier Management, LLC

A professional property management website for Saint Johns Premier Management, LLC, serving Saint Johns County, Florida.

## Tech Stack

- **Framework**: TanStack Start (React, SSR)
- **Styling**: Tailwind CSS v4
- **Forms**: Netlify Forms
- **Hosting**: Netlify
- **Language**: TypeScript

## Features

- Full marketing landing page (hero, services, about, stats, CTA)
- Dedicated contact page with a multi-field contact form
- Form submissions handled via Netlify Forms (no backend code needed)
- Responsive design optimized for mobile and desktop
- Custom domain: saintjohnspremiermgmt.com

## Running Locally

```bash
npm install
npm run dev
```

The dev server starts on http://localhost:3000. Note: Netlify Forms submissions only work on deployed Netlify environments, not locally.

## Deployment

This project is configured for Netlify. Push to the linked Git repository to trigger a deploy. The custom domain `saintjohnspremiermgmt.com` should be configured in the Netlify dashboard under **Domain Management**.
